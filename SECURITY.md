# Security Policy

## Supported Versions

Only the latest released version of this integration is supported with
security updates. Please make sure you are running the latest release
(check via HACS or the [Releases page](https://github.com/mosandlt/Bosch-Smart-Home-Camera-Tool-HomeAssistant/releases))
before reporting a security issue.

## Reporting a Vulnerability

If you discover a security vulnerability (e.g. credential leakage, unsafe
handling of tokens/secrets, injection issues, or anything that could expose a
user's Bosch Smart Home account or camera stream to unauthorized access),
please **do not open a public issue**.

Instead, report it privately using one of these channels:

* [GitHub Security Advisories](https://github.com/mosandlt/Bosch-Smart-Home-Camera-Tool-HomeAssistant/security/advisories/new) for this repository (preferred)
* A private message to the maintainer via their [GitHub profile](https://github.com/mosandlt)

Please include:

* A description of the vulnerability and its potential impact
* Steps to reproduce (logs/config with all secrets redacted)
* Any suggested fix, if you have one

## Response

We aim to acknowledge reports within a few days and to release a fix as soon
as reasonably possible once a vulnerability is confirmed. Credit will be
given in the release notes unless you prefer to remain anonymous.
